# Garuda Lingua Nusantara

Professional integrated GitHub Pages package for the **Garuda Lingua Nusantara** interactive monument website.

## Main Features

- Complete landing page without blank sections
- Interactive Garuda monument viewer
- Eight clickable hotspots
- Automatic QR change when a hotspot is selected
- Field-integrated content for:
  - English Language Teaching
  - ELF Pronunciation
  - Global Intelligibility
  - AI Literacy
  - ESP
  - Digital Learning
  - Research Ethics
  - Nusantara Heritage
- QR Learning Station with separate QR code for every field
- Voice Map prompts for pronunciation, intelligibility, and identity learning
- Professional scholarly dossier
- Working navigation and working Back to Top button

## Easy GitHub Deployment

1. Create a GitHub repository named `Garuda-Lingua-Nusantara`.
2. Upload all files from this folder directly into the repository root.
3. Make sure `index.html` is visible in the repository root.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Choose `main` and `/ root`.
7. Save.

Final URL:

`https://jslametpbi.github.io/Garuda-Lingua-Nusantara/`

## QR Codes

The QR codes are stored in:

`assets/qrs/`

Each QR code opens the corresponding anchor on the permanent GitHub Pages URL.
