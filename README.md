# Garuda Lingua Nusantara

Professional integrated monument learning platform for Garuda-Nusantara scholarly architecture.

## Included
- Exclusive redesigned home display with proportional gold typography.
- Philosophy page with clear monument-part visuals.
- Monument Spots with smooth rotatable viewer, 4D-style glow effects, exact symbolic hotspot placement, selected QR access, and module integration.
- Learning Studio with English-skill tasks, varied assessments, Speaker controls with Play/Pause/Stop, and AI Coach.
- Indonesia Voice Map with clickable province markers and province buttons.
- Admin / Lecturer Dashboard protected by PIN `JS2026`.
- Materials Builder and Assessment Builder for admin/lecturer use.
- Copyright Dr. Joko Slamet.

## Deploy
Upload all files to the root of a GitHub Pages repository and activate Pages from `main` branch `/ root`.
