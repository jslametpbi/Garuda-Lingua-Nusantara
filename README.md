# Garuda Lingua Nusantara

Integrated Garuda–Nusantara monument learning platform with philosophy-based hotspots, QR learning routes, learning materials, assessments, Indonesia Voice Map, and protected Admin dashboard.

## Deploy
Upload all files to the root of a GitHub repository named `Garuda-Lingua-Nusantara`, then enable GitHub Pages from `main` branch and `/ root`.

## Admin
Open the Admin section and use the owner PIN. Edits are stored in browser localStorage and can be exported as JSON.
