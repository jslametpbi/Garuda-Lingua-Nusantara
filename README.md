# Garuda Lingua Nusantara

**Garuda Lingua Nusantara** is a professional static website package for a research-based monumental artwork with Garuda and Nusantara nuances. The concept connects Indonesian identity, English Language Teaching, ELF pronunciation, global intelligibility, AI-supported learning, ESP, digital learning, ethics, and international scholarly contribution.

## Recommended permanent URL

Create a GitHub repository with this exact name:

```text
Garuda-Lingua-Nusantara
```

After uploading this package and enabling GitHub Pages, the project URL should be:

```text
https://jslametpbi.github.io/Garuda-Lingua-Nusantara/
```

## Files included

- `index.html` — main landing page
- `styles.css` — professional visual styling
- `app.js` — navigation, animation, interactive concept viewer, copy URL button
- `assets/garuda-lingua-nusantara-design-board.png` — full visual design board
- `assets/garuda-lingua-nusantara-design-board-preview.jpg` — optimized website preview
- `assets/qr-proposed-url.png` — QR code for the recommended GitHub Pages URL
- `assets/favicon.png` — project icon
- `assets/manifest.json` — web app manifest
- `.nojekyll` — prevents Jekyll processing issues for static assets
- `.github/workflows/pages.yml` — optional GitHub Actions deployment workflow

## Easy GitHub Pages upload

1. Create a new GitHub repository named `Garuda-Lingua-Nusantara`.
2. Upload all files and folders from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** branch and **/ root** folder.
6. Save.
7. Open the published URL: `https://jslametpbi.github.io/Garuda-Lingua-Nusantara/`.

## Notes

- Keep `index.html` at the repository root.
- Do not upload the zip file itself; upload the extracted files.
- The QR code is prepared for the recommended URL. If you use another repository name, regenerate the QR code.
