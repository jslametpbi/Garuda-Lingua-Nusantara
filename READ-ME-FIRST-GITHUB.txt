GARUDA LINGUA NUSANTARA - EASY GITHUB PAGES DEPLOY

UPLOAD METHOD: GitHub website only, no coding required.

IMPORTANT:
1. Do NOT upload this ZIP as one file.
2. Extract/unzip it first.
3. Upload ALL extracted files and folders to the root/top level of your GitHub repository.
4. Make sure index.html is visible directly in the first page of the repository, not inside another folder.

RECOMMENDED REPOSITORY NAME:
Garuda-Lingua-Nusantara

EXPECTED PERMANENT URL AFTER GITHUB PAGES IS ACTIVE:
https://jslametpbi.github.io/Garuda-Lingua-Nusantara/

STEP BY STEP:
1. Go to GitHub.com and log in.
2. Click + then New repository.
3. Repository name: Garuda-Lingua-Nusantara
4. Choose Public.
5. Click Create repository.
6. Click Add file > Upload files.
7. Drag and drop ALL extracted files and folders from this package.
8. Click Commit changes.
9. Go to Settings > Pages.
10. Source: Deploy from a branch.
11. Branch: main.
12. Folder: / root.
13. Click Save.
14. Open the published URL after GitHub Pages finishes publishing.

FILES INCLUDED:
- index.html = main website page
- styles.css = professional visual design styling
- app.js = website interactions
- assets/ = design board, QR image, favicon, preview images, manifest
- .nojekyll = prevents GitHub from changing static asset handling
- README.md = GitHub repository description
- DEPLOYMENT-GUIDE.txt = extra deployment guide

TROUBLESHOOTING:
- Blank page: check that index.html is in repository root, not inside a folder.
- Image missing: check that the assets folder was uploaded.
- 404 page: wait until GitHub Pages finishes publishing, then refresh.
- Wrong URL: check repository name spelling.
