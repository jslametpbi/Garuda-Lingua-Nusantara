EASY DEPLOYMENT

1. Extract this ZIP.
2. Create a new GitHub repository: Garuda-Lingua-Nusantara
3. Upload ALL extracted files and folders into the repository root.
4. Do not upload the ZIP itself.
5. Confirm that index.html appears directly in the root.
6. Go to Settings > Pages.
7. Source: Deploy from a branch.
8. Branch: main.
9. Folder: / root.
10. Save.
